An ORM for your package managers

abxpkg provides consistent interfaces for runtime dependency resolution & installation across many package managers and OSs, built with pydantic v2 for strong static typing and easy conversion to/from JSON. It's usable with Django, django-ninja, and OpenAPI tools, and its driver layer can be pyinfra, ansible, or the built-in abxpkg engine.

Originally built by ArchiveBox to install & auto-update extractor dependencies at runtime (chrome, wget, curl, etc.) on macOS / Linux / Docker.
